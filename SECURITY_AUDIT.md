# АУДИТ БЕЗОПАСНОСТИ И АНАЛИЗ УЯЗВИМОСТЕЙ ПРОЕКТА

В данном документе приведён всесторонний аудит безопасности компонентов системы развертывания `Veyon_Flash`, скриптов автоматизации, веб-сервера и C++ исходников.

---

## 1. СТРОЖАЙШИЙ ПРИНЦИП ЗАЩИТЫ УЧЁТНЫХ ДАННЫХ ПРЕПОДАВАТЕЛЯ

> [!CAUTION]
> **ПРАВИЛО №1 БЕЗОПАСНОСТИ ПРОЕКТА:**
> Компьютер учителя работает под локальной учётной записью `Lolo` с паролем преподавателя.
> * **Запрет 1:** Учётные данные преподавателя **категорически запрещено** вносить в какие-либо скрипты, базы данных, конфигурации или репозитории.
> * **Запрет 2:** Скрипт `setup_student.ps1` **нельзя запускать на ПК учителя**, так как он автоматически переименует текущего пользователя в `Student`. На ПК учителя запускается исключительно `setup_master.ps1`.
> * **Запрет 3:** Файлы на флешке предназначены для учащихся, следовательно, на флешке не должно быть личных данных, паролей и закрытых ключей преподавателя в открытом доступе.

## 2. АНАЛИЗ ВЫЯВЛЕННЫХ УЯЗВИМОСТЕЙ И РИСКОВ

### Уязвимость 1: Неавторизованная раздача приватного RSA-ключа в `server.py`
* **Файл:** `data/server.py`, строки 303–314
* **Фрагмент кода:**
  ```python
  # Раздача файлов установщика и ключей
  if path.startswith("/files/"):
      filename = os.path.basename(path)
      filepath = os.path.join(BASE_DIR, filename)
      if os.path.exists(filepath):
          self.send_response(200)
          self.send_header("Content-Type", "application/octet-stream")
          self.send_header("Content-Length", str(os.path.getsize(filepath)))
          self.end_headers()
          with open(filepath, "rb") as f:
              while chunk := f.read(65536):
                  self.wfile.write(chunk)
          return
  ```
* **Суть риска:** Каталог `BASE_DIR` содержит файл `admin_private_key.pem`. Любой ученик в классе, подключившись к веб-панели по адресу `http://<IP_Учителя>:8080/files/admin_private_key.pem`, может скачать закрытый ключ администратора Veyon. Обладая этим ключом, любой компьютер в сети может перехватить управление всеми мониторами класса.
* **Рекомендация по исправлению:** Добавить белый список разрешённых для скачивания файлов:
  ```python
  ALLOWED_FILES = {"veyon-setup.exe", "admin_public_key.pem", "setup_student.ps1"}
  if filename not in ALLOWED_FILES:
      self.send_response(403)
      self.end_headers()
      return
  ```

### Уязвимость 2: Открытое хранение пароля в реестре Windows (`Winlogon`)
* **Файл:** `data/setup_student.ps1`, строки 101–103
* **Фрагмент кода:**
  ```powershell
  Set-ItemProperty -Path $winlogonKey -Name "ForceAutoLogon" -Value "1" -Type String -Force
  Set-ItemProperty -Path $winlogonKey -Name "DefaultUserName" -Value "Student" -Type String -Force
  Set-ItemProperty -Path $winlogonKey -Name "DefaultPassword" -Value "[REDACTED]" -Type String -Force
  ```
* **Суть риска:** Механизм `Winlogon\DefaultPassword` является нативным стандартом Windows для автологина, однако пароль хранится в открытом незашифрованном виде в ветке `HKLM`. Любой процесс с правами администратора (или чтением этой ветки) может прочитать пароль.
* **Оценка применимости:** Для учебного класса информатики, где все ученические компьютеры имеют общий публичный пароль `Student` и являются взаимозаменяемыми терминалами, данный риск является **штатным и допустимым**, так как на машинах учеников не хранятся персональные тайны.

### Уязвимость 3: Неаутентифицированное удалённое управление в веб-панели
* **Файл:** `data/server.py`, строки 326–355
* **Суть риска:** API-эндпоинты `/api/reboot_all`, `/api/shutdown_all`, `/api/logon_all` не требуют авторизации (Basic Auth / Bearer token). Любой пользователь локальной подсети `192.168.1.0/24`, отправив POST-запрос на порт 8080 компьютера учителя, может инициировать перезагрузку или выключение всех ПК.
* **Рекомендация:**
  1. Привязать сервер `server.py` исключительно к интерфейсу `127.0.0.1`, если удалённая установка по сети не требуется.
  2. Либо добавить простой токен аутентификации для доступа к управляющим маршрутам.

### Уязвимость 4: Хардкод дефолтного пароля в C++ исходниках Veyon
* **Файл:** `plugins/usersessioncontrol/UserSessionControlPlugin.cpp`, строка 93
* **Фрагмент кода:**
  ```cpp
  const auto password = settings.value( QStringLiteral("AutoLogin/Password"), QStringLiteral("[REDACTED]") ).toByteArray();
  ```
* **Суть риска:** Пароль по умолчанию был жестко вкомпилирован в бинарник `usersessioncontrol.dll`. При декомпиляции или обычном поиске строк в DLL пароль легко извлекается.
* **Рекомендация:** Пароль должен всегда шифроваться с использованием мастер-ключа через встроенный криптографический модуль `VeyonCore::cryptoCore().encryptPassword()`.
