## 2. ПОДРОБНЫЙ РАЗБОР КЛЮЧЕВЫХ ТЕСТОВ

### Тест 1 и 2: Валидация синтаксиса PowerShell
Скрипты `setup_student.ps1` и `setup_master.ps1` были протестированы через штатный лексер и парсер абстрактного синтаксического дерева PowerShell:
```powershell
$tokens = $null; $errors = $null;
$ast = [System.Management.Automation.Language.Parser]::ParseInput((Get-Content 'setup_student.ps1' -Raw), [ref]$tokens, [ref]$errors)
# Результат: $errors.Count == 0 (SYNTAX OK)
```

### Тест 3 и 6: Проверка работоспособности веб-сервера `server.py`
Скрипт был запущен в изолированном контексте:
* Проверено чтение 13 компьютеров из файла `computers_list.txt`.
* Локальный сетевой адрес ПК учителя успешно определён как `192.168.1.25`.
* Генерация однострочника для быстрой установки подтверждена:
  `powershell -WindowStyle Hidden -ExecutionPolicy Bypass -Command "irm http://192.168.1.25:8080/setup | iex"`

### Тест 9 и 10: Диагностика C++ сборок и деплоя
Аудит истории коммитов репозитория `C:\Users\Lolo\veyon` и журнала GitHub Actions показал:
* Изменения в `plugins/platform/windows/WindowsUserFunctions.cpp` никогда не компилировались на GitHub Actions, так как файл сборки `.github/workflows/build-windows.yml` содержал только вызов `ninja usersessioncontrol`.
* На клиентах учеников никогда не запускался модифицированный код, так как использовался штатный установщик `veyon-setup.exe`.
