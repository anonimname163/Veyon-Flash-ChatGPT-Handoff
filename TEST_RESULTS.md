## 2. Подробный протокол ключевых тестов

### Тест T-08: Реальный прогон `diagnostics.ps1`
* **Команда:** `powershell -NoProfile -ExecutionPolicy Bypass -File "data\diagnostics.ps1"`
* **Результат выполнения:**
  * Операционная система: Windows 11 Pro 10.0.26300 (AMD64)
  * Сетевой адаптер: Qualcomm Atheros QCA9377 Wireless (IPv4: `192.168.1.25`, MAC: `E8:D0:FC:72:38:E5`)
  * Связь со шлюзом `192.168.1.1`: `OK (Доступен)`
  * Установленный Veyon: `4.11.3`
  * Служба `VeyonService`: `Running (Automatic)`
  * Порт 11100: `СЛУШАЕТСЯ`
  * Проверка реестра: `DefaultUserName: Lolo`, `AutoAdminLogon: 1`
  * Запись отчёта: `C:\ProgramData\Veyon_Flash\diagnostics_report.txt` сформирован успешно.

### Тест T-09: Проверка защиты компьютера учителя (Teacher Guard)
* **Проверка:** Инициализация логики проверки на компьютере преподавателя:
  ```powershell
  $isTeacherDetected = ($env:USERNAME -eq 'Lolo') -or ((& veyon-cli authkeys list) -match 'admin/private')
  # Результат: $true
  ```
* **Поведение:** Скрипт `setup_student.ps1` немедленно завершает работу с кодом `2`, предотвращая повреждение профиля преподавателя.
