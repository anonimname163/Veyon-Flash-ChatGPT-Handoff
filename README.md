# Veyon-Flash-ChatGPT-Handoff

Пакет полной передачи технического контекста проекта **Veyon_Flash** («проект_1») и форка **Veyon** для продолжения аудита и разработки в ChatGPT.

---

## 📌 О проекте

Проект решает комплексную задачу автоматизированной установки, конфигурации и управления компьютерным классом информатики («Информатика-1»: ~15 клиентских компьютеров `PC-1` .. `PC-12`, `main-pc` и 1 ПК учителя/мастера).

Ключевая инженерная проблема, решаемая проектом — устранение сбоев входа в систему Windows 10/11 при использовании Veyon (блокировка шторкой экрана блокировки, некорректная раскладка клавиатуры `RU/EN`, баги ядра `prepareLogon()` и смещение фокуса ввода).

---

## 🏗️ Архитектурное разделение трёх подсистем

> [!IMPORTANT]
> Для правильного понимания проекта крайне важно различать **три независимые подсистемы**:

1. **Подсистема А: Комплект развертывания на флешке (`E:\`)**
   * Корневой диспетчер `VEYON.bat` с автоматическим запросом UAC (`RunAs`).
   * Скрипт `data/setup_student.ps1` (настройка ученика, нативный `Winlogon\ForceAutoLogon = 1`, снятие шторки `NoLockScreen`, установка английской раскладки `00000409` по умолчанию).
   * Скрипт `data/setup_master.ps1` (настройка мастера, генерация/импорт ключей, создание класса «Информатика-1» с 13 ПК).
   * Список ПК `data/computers_list.txt` (база MAC и IP для Wake-on-LAN).

2. **Подсистема Б: Повседневное управление уроком (Veyon Master GUI)**
   * Официальный интерфейс **Veyon Master** на компьютере учителя.
   * Мониторинг экранов учащихся, удалённая помощь, показ экрана учителя, передача файлов, блокировка ввода, завершение работы.
   * **Веб-панель НЕ заменяет Veyon Master!** Веб-панель (`server.py`) — это сугубо вспомогательный инструмент первоначального обхода и сетевого развертывания (`irm http://.../setup | iex`).

3. **Подсистема В: Модификации исходного кода Veyon (C++ Fork)**
   * Репозиторий `C:\Users\Lolo\veyon` (форк апстрима Veyon 4.9.6, ветка `main`).
   * Модификация плагина `UserSessionControlPlugin.cpp`: удаление окна ввода логина/пароля в GUI мастера, добавление фичи смены пароля `m_setPasswordFeature`, эмуляция ввода на клиенте.
   * Модификация платформы `WindowsUserFunctions.cpp`: исправление бага вызова `performLogon()` при пустой сессии, сброс шторки, отправка только пароля.
   * **Текущий статус:** Изменения в C++ **пока не активны на клиентах**, так как на них развернут оригинальный бинарный релиз Veyon 4.9.6, а CI компилировал только `usersessioncontrol.dll` без `windows-platform.dll`.

## 🛡️ Политика защиты конфиденциальных данных

В данном пакете строго соблюдены требования безопасности:
* Все пароли учетных записей заменены на токены вида `[REDACTED_PASSWORD]`.
* Содержимое RSA/PEM ключей доступа заменено на `[REDACTED_RSA_KEY]`.
* Реальные MAC-адреса устройств частично замаскированы.
* Учётные данные и персональные идентификаторы администратора полностью исключены.
